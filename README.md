# Ubuntu L10n

Ubuntu/Launchpad translation statistics viewer.

Built with GTK4/Adwaita. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install ubuntu-l10n
```

### Fedora/RPM
```bash
sudo dnf install ubuntu-l10n
```
